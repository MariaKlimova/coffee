# Glossary — Coffee Shop

Единые термины для UI и документации. Skill: `product-voice`.

| Термин | Использовать | Не использовать |
|--------|--------------|-----------------|
| Кофе | зерно / молотый / напиток в каталоге | «sku кофе», «product type coffee» в UI |
| Кофемашина | техника для приготовления | «machine entity», «device» |
| Помол | степень помола зерна | «grind_level» в UI без пояснения |
| Корзина | список товаров к заказу | «cart payload» |
| Корзина: действия | «В корзину», «Добавить в корзину» | «Add to cart», «Add to bag» |
| Корзина: успех | «Добавлено в корзину» | «Added to cart», «Item added» |
| Корзина: ошибка | «Не удалось добавить в корзину. Попробуй ещё раз» | «Cart failed», «Add to cart error» |
| Корзина: количество | «Количество», «Уменьшить количество», «Увеличить количество» | «Qty», «Decrease», «Increase» |
| Корзина: страница | «Корзина», «Загрузка корзины», «Итого», «Оформить заказ», «Удалить» | «Cart», «Checkout», «Remove» |
| Корзина: пусто | «Корзина пока пуста», «Загляни в каталог — выбери то, что хочется попробовать», «В каталог» | «Cart is empty», «Перейти в каталог» |
| Корзина: ошибка загрузки | «Не удалось загрузить корзину» | «Failed to load cart» |
| Избранное | сохранённые товары | «favorites array» |
| Избранное: действия | «В избранное», «Убрать из избранного» | «Add to wishlist», «Unfavorite» |
| Избранное: гость | «Войди, чтобы добавить в избранное» | «Login required», «Sign in to favorite» |
| Избранное: ошибка | «Не удалось обновить избранное. Попробуй ещё раз» | «Favorite failed», «Could not update favorites» |
| Избранное: страница | «Избранное», «Загрузка избранного» | «Favorites», «Loading favorites» |
| Избранное: пусто | «Здесь пока пусто», «Отмечай сердечком то, что понравилось — вернёшься к этому позже», «В каталог» | «No favorites», «Wishlist empty», «Перейти в каталог» |
| Избранное: ошибка загрузки | «Не удалось загрузить избранное» | «Failed to load favorites» |
| Оформление заказа | checkout-поток | «submit order DTO» |
| Оформление: страница | «Оформление заказа», «Твой заказ», «Адрес доставки», «Оплатить» | «Checkout», «Pay now», «Submit order» |
| Оформление: гость | «Почта», «Телефон» на чекауте | «guest_email», «Contact fields» |
| Оформление: пусто | «В корзине пока пусто — сначала добавь товары» | «Nothing to checkout» |
| Оформление: недоступно | понятное сообщение с названиями позиций | сырой `unavailable_products` |
| Оформление: ошибка | «Не удалось оформить заказ. Попробуй ещё раз», «Не удалось перейти к оплате. Попробуй ещё раз» | «Order failed», «Payment error» |
| Результат оплаты: успех | «Заказ оплачен», «Номер заказа», «Перейти к заказам», «На главную» | «Payment success», «Order paid» |
| Результат оплаты: ожидание | «Обрабатываем оплату», «Обычно это занимает несколько секунд» | «Processing payment», «Waiting for webhook» |
| Результат оплаты: задержка | «Оплата обрабатывается дольше обычного», «Статус появится в Мои заказы» | «Payment delayed», «Still pending» |
| Результат оплаты: ошибка | «Оплата не прошла», «Попробовать снова» | «Payment failed», «Retry payment» |
| Каталог | витрина товаров | «products list endpoint» |
| CTA в каталог | «В каталог» | «Перейти в каталог», «В products» |
| Навигация | Главная, Кофе, Кофемашины, Контакты | «Home», «Catalog», «Machines» в UI |

| В наличии | «Только в наличии», «Нет в наличии» | «in_stock», «available» |
| Фильтры | «Фильтры» | «filters panel», «FilterBar» |

| Сбросить фильтры | «Сбросить фильтры» | «Reset filters», «Clear» |
| Пустой каталог | «Ничего не нашлось», «Попробуй изменить фильтры или сбросить их» | «No results», «empty state» |
| Ошибка каталога | «Не удалось загрузить каталог», «Не удалось открыть товар», «Попробовать ещё раз» | «Request failed», «HTTP error» |
| Страница | «Назад», «Вперёд», номера страниц в пагинации | «Previous», «Next», «pagination» |
| Товар не найден | «Не нашли такой товар», «Возможно, ссылка устарела — посмотри, что есть в каталоге» | «404», «Product not found», «Invalid slug» |
