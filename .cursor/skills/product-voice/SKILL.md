# Product voice — Coffee Shop

## Тон

- Спокойный, тёплый, на «ты»
- Без CAPS и лишних восклицаний
- Предложения и помощь, не приказы

## Запрещено в UI

- Сырой жаргон API (`sku`, `entity`, `payload`, `HTTP 422`) без человеческой формулировки
- Разные названия одного понятия (смотри [docs/content/glossary.md](../../../docs/content/glossary.md))

## Примеры

| Плохо | Хорошо |
|-------|--------|
| `POST /cart/items failed` | Не удалось добавить в корзину. Попробуй ещё раз |
| Product ID required | Выбери товар, чтобы добавить в корзину |
