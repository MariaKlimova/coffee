# Локальные шрифты

Витрина поставляет Inter и Lora вместе с приложением. `fonts.css` импортируется
из `src/main.tsx`; Vite выпускает WOFF2 с хешами в `dist/assets`. Во время открытия
сайта запросы к Google Fonts не нужны. `font-display: swap` сразу оставляет
читаемый системный шрифт, если локальный файл ещё загружается или недоступен.

Шкала, fallback и начертания остаются в `../tokens.css`: Inter normal 400/500/600,
Lora normal 500/600. Variable WOFF2 обслуживает несколько весов одним файлом.
Сохранены все Unicode-подмножества ответа Google Fonts, включая кириллицу,
расширенную латиницу, греческий, вьетнамский, математические символы и знаки.
Браузер загружает подмножество только при использовании соответствующих символов;
предзагрузка всех файлов не нужна. Размеры шрифта заданы прежними rem-токенами,
масштабирование браузера не ограничено.

## Источник и лицензии

Неизменённые WOFF2 получены 2 ноября 2026 года из официального CSS API Google Fonts:
[Inter 400–600 и Lora 500–600](https://fonts.googleapis.com/css2?family=Inter:wght@400..600&family=Lora:wght@500..600&display=swap).
В `sources.json` сохранены исходные URL с версиями, размеры и SHA-256 каждого файла.
Повторное скачивание при build или открытии сайта не выполняется.

Оба семейства распространяются по SIL Open Font License 1.1. Полные тексты
лицензий с copyright включены рядом: `inter-OFL.txt` и `lora-OFL.txt`. Источник
лицензий — [google/fonts](https://github.com/google/fonts), URL закреплены на commit
в `sources.json`. Внутренние имена шрифтов и сами WOFF2 не изменены.
`frontend/index.html` ссылается на лицензии через `rel="license"`: Vite включает
оба текста в production assets, поэтому они доступны и в опубликованной сборке.
Эти ссылки не подключают stylesheet и не блокируют отображение.

## Размер

Все 14 WOFF2 занимают **377 120 байт** (368,3 KiB). Для обычного русского/английского
экрана нужны четыре подмножества Inter/Lora Cyrillic + Latin: **126 220 байт**
(123,3 KiB) до HTTP-заголовков. Остальные файлы не запрашиваются без нужных символов.
Это размер файлов, уже сжатых в WOFF2; gzip-оценка для них не используется.

При обновлении сверить `sources.json`, лицензии, Unicode ranges и фактический размер
production assets. Увеличение полного набора сверх **400 KiB** требует объяснения
в PR. Зависимости npm и загрузчики сторонних шрифтов не добавлены.
